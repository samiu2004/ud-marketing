Is your LLC really registered? Here’s how to check.

Go beyond a PDF. Find the official state record and understand what it can—and cannot—tell you.

Start with the state, not the certificate

A polished PDF is a starting point, not your final check. Ask your provider for the exact legal company name, the formation state, the filing date, and the state-issued entity or file number. Keep those details together before searching.

Find the official registry

Use the state’s business registration office. The SBA’s state directory below is a useful starting point. Search for the exact legal name or file number; an internet search result, social profile, or private directory is not a substitute for the state record.

Compare the details

Match the company name, entity type, formation date, and file number to your documents. Check the status wording and registered agent information shown by that state. Availability of owner names and documents varies. A missing owner name alone does not prove something is wrong.

If you cannot find your company

Try the file number and a shorter version of the name. Check you selected the correct state and allow for filing processing time. Ask your provider for the official filing receipt. If the result still does not match, contact the state office using contact details from its own website.

Know the limits of the check

A registry record confirms information held by the state. It does not establish that a bank account exists, prove an EIN is genuine, confirm tax filings, or certify that an agent is trustworthy. Verify those separately with the relevant institution.
